"# Customer-Intelligence-support" 


"## Problem Statement"
The rapid growth of customer support requests across SaaS, e-commerce, and technology companies has made traditional manual ticket management inefficient, time-consuming, and costly. This project focuses on developing an AI-powered Customer Support Intelligence Platform that can automate important stages of the customer support process using the Customer Support Ticket Dataset from Kaggle.

The platform performs three major tasks. First, it classifies customer support tickets into categories such as Billing, Technical, Account, and Product Inquiry by analyzing the Ticket Subject and Ticket Description using Natural Language Processing (NLP) and a fine-tuned DistilBERT model. Second, it predicts the priority of each ticket as Low, Medium, High, or Critical using structured customer and ticket-related information such as product, channel, and customer age through tabular machine learning techniques. Finally, the system estimates the expected resolution time in hours by combining both textual and structured features using regression models.

Overall, the project aims to reduce manual effort, improve ticket routing and prioritization, provide more consistent support decisions, and help organizations manage customer issues more efficiently.
